# 「著」轉「着」用本地啟發式，zhù 類靠保護詞表按住

OpenCC 的 `TSCharacters` **不含「著」**：同一個字形要按讀音分派——`zhe`（盯著、沿著）、`zhuó`（附著、著手）在簡體作「着」，`zhù`（著作、著名、顯著）仍作「著」。字級表無法判斷，所以 OpenCC 乾脆不動它，留給詞表。

本庫語料裡含「著」的註釋共 84 條，實測**幾乎全是助詞用法**（盯著、挨著、趴著、蹲著、跟著、板著臉孔…），zhù 類只有 `著名`、`著作`、`顯著` 寥寥幾處。若照 OpenCC 默認不動，開著簡體渲染讀到「盯著」「沿著」會很刺眼。

決定：在 `tools/build_simplifier.py` 裡疊一層本地規則——字表加一條 `著 → 着`，另維護一張 zhù 類保護詞表（21 個詞：著名、著作、著者、顯著、編著、論著、原著、譯著、專著、巨著、名著、遺著…）。生成時把保護詞逐字轉成簡體後寫進 `phrases`，運行時**詞級最長匹配優先於字級**，所以保護詞整條命中、其餘「著」一律落字表變「着」。

## Considered Options

- **照 OpenCC 不動「著」**：零風險，但 84 條註釋裡的助詞「著」全部殘留，開關形同半殘。
- **逐條人工標註**：最準，但要維護者看完 84 條並隨語料增長反覆維護；性價比不如一張 21 詞的白名單。

## Consequences

這是「默認轉 + 白名單」結構：**沒被列進 `ZHU_KEEP` 的 zhù 類詞會被誤轉成「着」**（例如罕見的書名、專名）。語料新增 zhù 用法時要往那張表裡補，改完重跑 `build_simplifier.py` 即可。保護詞表寫在腳本常數裡而非運行時，是為了讓它可審、可 diff。
