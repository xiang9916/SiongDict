# 「著」转「着」用本地启发式，zhù 类靠保护词表按住

OpenCC 的 `TSCharacters` **不含「著」**：同一个字形要按读音分派——`zhe`（盯着、沿着）、`zhuó`（附着、着手）在简体作「着」，`zhù`（著作、著名、显著）仍作「著」。字级表无法判断，所以 OpenCC 干脆不动它，留给词表。

本库语料里含「著」的注释共 84 条，实测**几乎全是助词用法**（盯着、挨着、趴着、蹲着、跟着、板着脸孔…），zhù 类只有 `著名`、`著作`、`显著` 寥寥几处。若照 OpenCC 默认不动，开着简体渲染读到「盯着」「沿着」会很刺眼。

决定：在 `tools/build_simplifier.py` 里叠一层本地规则——字表加一条 `著 → 着`，另维护一张 zhù 类保护词表（21 个词：著名、著作、著者、显著、编著、论著、原著、译著、专著、巨著、名著、遗著…）。生成时把保护词逐字转成简体后写进 `phrases`，运行时**词级最长匹配优先于字级**，所以保护词整条命中、其余「著」一律落字表变「着」。

## Considered Options

- **照 OpenCC 不动「著」**：零风险，但 84 条注释里的助词「着」全部残留，开关形同半残。
- **逐条人工标注**：最准，但要维护者看完 84 条并随语料增长反复维护；性价比不如一张 21 词的白名单。

## Consequences

这是「默认转 + 白名单」结构：**没被列进 `ZHU_KEEP` 的 zhù 类词会被误转成「着」**（例如罕见的书名、专名）。语料新增 zhù 用法时要往那张表里补，改完重跑 `build_simplifier.py` 即可。保护词表写在脚本常数里而非运行时，是为了让它可审、可 diff。
