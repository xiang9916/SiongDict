# 十六调关系记录表（湘语祖型→今调对应）

## 用途

本表记录湘语若干方言点、以及长沙三个读音层次在中古十六个声调细分下的今调类归并，
用于查阅「某方言点（某层）的某一中古声调类别，今读第几调」，
是判定同源词音类、核对文读／白读层调类归并的长期参考资料。

## 读法

- **行**：一行一个方言点。长沙按文读层、核心白读层、边缘白读层分三行；湘乡单列一行。长沙双江同样分文读／核心白读／边缘白读三层（2026-11-09 由维护者提供，见附注 6）。
  `方言点1（文读层）`、`方言点1（白读层）` 两行是预留的占位模板，源表尚未录入任何调类。
- **列**：`已人工确认` 记该行是否已由维护者人工核定（源表为布尔值，本文写作「是」「否」）。
  其后 16 列即「十六调细分」：平、上、去、入四声各按全清、次清、全浊、次浊四类声母分开。
  表头以 `·` 连接两段——前段是祖型声调（阴平1、阳平2、阴上3、阳上4、阴去5、阳去6、阴入7、阳入8），
  后段是该祖型下的清浊细分（阴调类对应全清、次清，阳调类对应全浊、次浊）。
- **单元格值**：今调类编号（1＝阴平，2＝阳平，3＝阴上，4＝阳上，5＝阴去，6＝阳去，7＝阴入，8＝阳入），
  是调类编号而非五度制调值；湘乡另用 `2a`／`2b`、`5a`／`5b` 表示同一调类的再分调（见附注 1）。
  单元格为空表示源表该格未填值，本文照空保留，不作推测补写。
- **文读层／白读层**：文读层指读书音一层，白读层指口语音一层；长沙的白读层又分「核心」与「边缘」两套。
- **查法示例**：查「长沙（核心白读层）」的全浊上今调，在「长沙（核心白读层）」行、「阳上4·全浊上」列读到 `6`；
  同一格在文读层为 `5`、边缘白读层为 `3`（三层差异见附注 2）。

## 附注

1. **湘乡的 2a／2b、5a／5b 再分调**：湘乡的阳平 2 再分为 `2a`／`2b`，阴去 5 再分为 `5a`／`5b`。
   表内对应关系为：全浊平→`2a`、次浊平→`2b`，全清去→`5a`、次清去→`5b`；
   入声则全清入→`2b`、次清入→`2a`、全浊入→`5b`、次浊入→`5a`
   （即湘乡入声按清浊分别并入 2a／2b 与 5a／5b 两组再分调）。
2. **长沙三层的差异**：以「文读层／核心白读层／边缘白读层」为序，表内取值不同的列是——
   次浊平 2／2／1、全浊上 5／6／3、全浊去 5／6／6、次浊去 5／6／6、全浊入 7／7／5、次浊入 7／7／5；
   其余十列三层一致。
3. **崇阳、桃源的全浊上**：两点的全浊上均归 6（长沙文读层归 5，见附注 2）。
   另桃源的全浊入、次浊入均归 6，而崇阳这两列仍为 7。
4. **占位行**：`方言点1（文读层）`、`方言点1（白读层）` 是预留给其他方言点的空行；
   源表只填了行名与「已人工确认＝否」，16 个细分格全为空。本文照实保留空值，
   不得据此推断任何古今对应关系。
5. **空值**：源表空格一律保留为空；这些格子是「源表未记录」，不等于「该点无此调类」。

6. **长沙双江三层（2026-11-09 维护者提供）**：数值由维护者直接提供，未附源表布尔值，
   故三行「已人工确认」暂填「否」。三层差异列：次浊平 2／2／1、全清上·次清上 7／3／3、
   全浊去·次浊去 5／6／6、入声（文读 3／3／3／3，核心白读 7／7／7／7，边缘白读 7／7／6／6）；

### 推导方法与取值约定

1. **数据源**：`app/src/main/assets/databases/siongdict.db` 的 `langs` 表（每行一个同音字组，组内各字共享同一读音）与 `info` 表（方言点元数据、声调系统）。读音经 `ipa_parser.parse_ipa()` 切分、`get_tone_category()` 归并（如 `2a`→`2`），取今调类编号。
2. **例字**：每个中古调类按全清、次清、全浊、次浊四类声母各选 2–4 个常用例字（例字集见附注 8–20），逐字查该点读音；同格例字读出同一调类才填该编号。
3. **同格不一致**：不取平均、不照抄邻点。可判定为文白／又读的，取该点核心层或与已确认点同型的值，另读列入附注；无法调和的记 `?` 并列两派例字（本次仅邵阳「阳去6·次浊去」一格）。
4. **分层**：望城的全浊上、全浊去、次浊去三列每字均有 5、6 两读，按长沙已确认层的「文读＝5、白读＝6」分列两行（层属推断，见附注 8、9）。
5. **覆盖面**：本次新增 12 个方言点、13 行；只增不删，不修改既有行。表中值为今调类编号，不是调值。

### 与已确认点的一致性检查

- **望城**两层分别与「长沙（文读层）」「长沙（核心白读层）」16 格全同；望城无长沙边缘白读层的 `1`／`3` 值。
- **寧鄉**与「长沙（核心白读层）」16 格全同（全浊上 6、全浊去 6、次浊去 6）。
- **瀏陽**与「长沙（文读层）」16 格全同（全浊上 5、全浊去 5、次浊去 5）；瀏陽在 `info` 中归赣语宜浏片，可作长沙文读型的旁证。
- **益陽、沅江**：阴去并入阳平（调类 `2`），与 `info.聲調` 的「陽平陰去」一致；入声独立为 `7`。
- **湘陰**：入声并入阴去 `5`（`info.聲調` 无 7 调），其余列与长沙核心白读层同型。
- **雙峰、婁底**：入声分派与「湘乡」已确认行同型——清入→`2`、浊入→`5`（湘乡再分 2a／2b、5a／5b），可互证。
- **衡山、衡陽西渡**：衡州片入声分派与长沙不同——衡山全浊入→`3`，衡陽西渡全浊入、次浊入均→`2`；未入表的衡东与衡山同型（全浊入→3），可佐证衡山一列。
- **平江**：阳上 `4` 独立（全浊上、次浊上均→4），与赣语大通片特征相符；与崇阳（全浊上→6）不同，属点间真实差异。
- **邵陽**：去声分派与长沙、湘乡均不同（次清去→6、次浊去 5／6 分裂），见附注 17 与报告冲突清单。
