# 十六调关系记录表（湘语祖型→今调对应）

## 用途

本表记录湘语若干方言点、以及长沙三个读音层次在中古十六个声调细分下的今调类归并，
用于查阅「某方言点（某层）的某一中古声调类别，今读第几调」，
是判定同源词音类、核对文读／白读层调类归并的长期参考资料。

## 读法

- **行**：一行一个方言点。长沙按文读层、核心白读层、边缘白读层分三行；湘乡单列一行。
  `方言点1（文读层）`、`方言点1（白读层）` 两行是预留的占位模板，源表尚未录入任何调类。
- **列**：`已人工确认` 记该行是否已由维护者人工核定（源表为布尔值，本文写作「是」「否」）。
  其后 16 列即「十六调细分」：平、上、去、入四声各按全清、次清、全浊、次浊四类声母分开。
  表头以 `·` 连接两段——前段是祖型声调（阴平1、阳平2、阴上3、阳上4、阴去5、阳去6、阴入7、阳入8），
  后段是该祖型下的清浊细分（阴调类对应全清、次清，阳调类对应全浊、次浊）。
- **单元格值**：今调类编号（1＝阴平，2＝阳平，3＝阴上，4＝阳上，5＝阴去，6＝阳去，7＝阴入，8＝阳入），
  是调类编号而非五度制调值；湘乡另用 `2a`／`2b`、`5a`／`5b` 表示同一调类的再分调（见附注 1）。
  单元格为空表示源表该格未填值，本文照空保留，不作推测补写。
- **文读层／白读层**：文读层指读书音一层，白读层指口语音一层；长沙的白读层又分「核心」与「边缘」两套。
- **查法示例**：查「长沙（核心白读层）」的全浊上今调，在「长沙（核心白读层）」行、「阳上4·全浊上」列读到 `6`；
  同一格在文读层为 `5`、边缘白读层为 `3`（三层差异见附注 2）。

## 附注

1. **湘乡的 2a／2b、5a／5b 再分调**：湘乡的阳平 2 再分为 `2a`／`2b`，阴去 5 再分为 `5a`／`5b`。
   表内对应关系为：全浊平→`2a`、次浊平→`2b`，全清去→`5a`、次清去→`5b`；
   入声则全清入→`2b`、次清入→`2a`、全浊入→`5b`、次浊入→`5a`
   （即湘乡入声按清浊分别并入 2a／2b 与 5a／5b 两组再分调）。
2. **长沙三层的差异**：以「文读层／核心白读层／边缘白读层」为序，表内取值不同的列是——
   次浊平 2／2／1、全浊上 5／6／3、全浊去 5／6／6、次浊去 5／6／6、全浊入 7／7／5、次浊入 7／7／5；
   其余十列三层一致。
3. **崇阳、桃源的全浊上**：两点的全浊上均归 6（长沙文读层归 5，见附注 2）。
   另桃源的全浊入、次浊入均归 6，而崇阳这两列仍为 7。
4. **占位行**：`方言点1（文读层）`、`方言点1（白读层）` 是预留给其他方言点的空行；
   源表只填了行名与「已人工确认＝否」，16 个细分格全为空。本文照实保留空值，
   不得据此推断任何古今对应关系。
5. **空值**：源表空格一律保留为空；这些格子是「源表未记录」，不等于「该点无此调类」。
